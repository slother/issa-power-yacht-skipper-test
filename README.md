# ISSA Power Yacht Skipper — ABCD practice quiz

Interactive practice quiz for ISSA Inland Power Yacht Skipper, available in Polish and English. It has 93 questions, including illustrated inland-waterway marks and navigation-light sectors. Select **Polski** or **English** on the page to switch languages; your answers remain in place.

Questions and original diagrams were prepared from the course textbook. This is not an official ISSA exam question bank.

To run locally, open `index.html` in a browser.

Interaktywny test przygotowujący do ISSA Inland Power Yacht Skipper w języku polskim i angielskim. Zawiera 93 pytania, w tym pytania obrazkowe o oznakowanie szlaku i światła nawigacyjne. Język zmienisz przyciskami **Polski** i **English** bez utraty zaznaczonych odpowiedzi.

Pytania i autorskie rysunki opracowano na podstawie podręcznika kursowego. Nie są to oficjalne pytania egzaminacyjne ISSA.

Aby uruchomić lokalnie, otwórz `index.html` w przeglądarce.
