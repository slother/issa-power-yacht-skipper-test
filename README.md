# ISSA Power Yacht Skipper — test ABCD

Interaktywny test przygotowujący do ISSA Inland Power Yacht Skipper. Zawiera 93 pytania, w tym pytania obrazkowe o oznakowanie szlaku i światła nawigacyjne.

Pytania i rysunki opracowano na podstawie podręcznika kursowego. Nie są to oficjalne pytania egzaminacyjne ISSA.

Aby uruchomić lokalnie, otwórz `index.html` w przeglądarce.
